## 🚀 About Me

I'm a **Cybersecurity Leader and Security Architect** based in the **United Arab Emirates**, with **18+ years in Information Technology specializing in cybersecurity**.

I design, build and improve enterprise cybersecurity capabilities across **Security Operations Centers (SOC), cloud and infrastructure security, threat detection, digital forensics, incident response and cybersecurity governance**.

My experience includes leading SOC teams and transformation initiatives; architecting SIEM/SOAR integrations; developing detection engineering and threat hunting capabilities; and supporting cloud security programs in highly regulated environments. I have worked across the **UAE, US, EMEA and Australia**, supporting government, financial services, healthcare, telecommunications, manufacturing and technology.

- 🛡️ **SOC Leadership:** SOC strategy, build-and-run operations, MDR, multi-tenant SOCs, service governance, KPIs and SLAs
- 🔎 **Threat Detection & DFIR:** SIEM use cases, threat hunting, malware triage, memory/disk/network forensics, incident response
- ☁️ **Cloud Security:** Azure, AWS, GCP, Huawei Cloud, hybrid and restricted-cloud architectures
- 🏗️ **Security Architecture:** SIEM, SOAR, EDR/XDR, NDR, IAM/PAM, threat intelligence, vulnerability management, log pipelines
- 📋 **Risk & Compliance:** ISO 27001, NIST CSF, CIS Controls, PCI DSS, GDPR, HIPAA and regional security frameworks
- 🤖 **Innovation:** Agentic SOC, AI-assisted investigations, security automation and automated GRC assessments
